# portfolio

My portfolio site. One page, black and white, built like a zine.

## Running it

    npm install
    npm run dev

## Stack

Next.js 16 with the App Router, Tailwind v4, GSAP and ScrollTrigger for the scroll
animation, Lenis for smooth scrolling. Type is PP Neue Montreal and PP Eiko,
self-hosted and subset.

Fonts are licensed for personal use and are not covered by this repo's licence.
